## 数据库设计

## 一、概念模型（ER）

### 1. 实体

- `sys_user`（用户）
- `forum_board`（板块）
- `forum_post`（帖子）
- `forum_comment`（评论）
- `forum_like`（点赞）

### 1.1 代码侧命名（驼峰）

- 业务实体类：`User`、`ForumBoard`、`ForumPost`、`ForumComment`、`ForumLike`
- 统计实体类：`StatOverview`、`StatHotPost`、`StatBoardActive`、`StatActiveUser`、`StatContentQuality`、`StatDailyTrend`
- Mapper XML：`UserMapper.xml`、`ForumBoardMapper.xml`、`ForumPostMapper.xml`、`ForumCommentMapper.xml`、`ForumLikeMapper.xml`、`StatMapper.xml`

### 2. 实体核心属性

#### `sys_user`（用户）

- 主键：`user_id`
- 唯一属性：`username`
- 主要属性：`password`、`nickname`、`avatar`、`signature`、`role`、`status`、`create_time`、`update_time`

#### `forum_board`（板块）

- 主键：`board_id`
- 主要属性：`board_name`、`description`、`sort_num`、`status`、`create_time`、`update_time`

#### `forum_post`（帖子）

- 主键：`post_id`
- 外键：`board_id` → `forum_board.board_id`，`author_id` → `sys_user.user_id`
- 主要属性：`title`、`content`、`view_count`、`like_count`、`comment_count`、`is_top`、`status`、`create_time`、`update_time`

#### `forum_comment`（评论）

- 主键：`comment_id`
- 外键：`post_id` → `forum_post.post_id`，`user_id` → `sys_user.user_id`
- 自关联外键：`parent_comment_id` → `forum_comment.comment_id`
- 可选外键：`reply_user_id` → `sys_user.user_id`
- 主要属性：`content`、`like_count`、`status`、`create_time`、`update_time`

#### `forum_like`（点赞）

- 主键：`like_id`
- 属性：`target_type`（1-帖子，2-评论）、`target_id`（目标ID）、`user_id` → `sys_user.user_id`
- 约束：`(target_type, target_id, user_id)` 唯一（同一用户不能重复点赞同一目标）
- 主要属性：`create_time`

### 3. 关系与基数

- 用户（`sys_user`）1 : N 帖子（`forum_post`）
- 板块（`forum_board`）1 : N 帖子（`forum_post`）
- 帖子（`forum_post`）1 : N 评论（`forum_comment`）
- 用户（`sys_user`）1 : N 评论（`forum_comment`）
- 评论（`forum_comment`）1 : N 子评论（`forum_comment` 自关联）
- 用户（`sys_user`）N : M 帖子（`forum_post`），通过 `forum_like`（target_type=1）关联
- 用户（`sys_user`）N : M 评论（`forum_comment`），通过 `forum_like`（target_type=2）关联

### 4. ER 结构（文本表达）

- `sys_user` --< `forum_post`
- `forum_board` --< `forum_post`
- `forum_post` --< `forum_comment`
- `sys_user` --< `forum_comment`
- `forum_comment` --< `forum_comment`（parent-child）
- `sys_user` --< `forum_like` >-- `forum_post`（当 target_type = 1）
- `sys_user` --< `forum_like` >-- `forum_comment`（当 target_type = 2）

---

## 二、逻辑模型（建表 SQL）

> 数据库方言：MySQL 8.0.x，字符集：`utf8mb4`，排序规则：`utf8mb4_unicode_ci`
> 说明：以下 SQL 与服务器实际运行数据库结构完全一致

```sql
CREATE TABLE `forum_board` (
  `board_id` bigint NOT NULL AUTO_INCREMENT COMMENT '板块ID',
  `board_name` varchar(100) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '板块名称',
  `description` varchar(500) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '板块描述',
  `sort_num` int NOT NULL DEFAULT '0' COMMENT '排序值',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态：1启用，0禁用',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`board_id`),
  UNIQUE KEY `uk_forum_board_name` (`board_name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='板块表';


CREATE TABLE `sys_user` (
  `user_id` bigint NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` varchar(50) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '登录账号',
  `password` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '密码（加密存储）',
  `nickname` varchar(50) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '昵称',
  `avatar` varchar(255) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '头像地址',
  `signature` varchar(255) COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '个性签名',
  `role` varchar(20) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT 'USER' COMMENT '角色：USER/ADMIN',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态：1启用，0禁用',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `uk_sys_user_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';


CREATE TABLE `forum_post` (
  `post_id` bigint NOT NULL AUTO_INCREMENT COMMENT '帖子ID',
  `board_id` bigint NOT NULL COMMENT '所属板块ID',
  `author_id` bigint NOT NULL COMMENT '作者用户ID',
  `title` varchar(200) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '帖子标题',
  `content` longtext COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '帖子内容（富文本）',
  `view_count` int NOT NULL DEFAULT '0' COMMENT '浏览量',
  `like_count` int NOT NULL DEFAULT '0' COMMENT '点赞数',
  `comment_count` int NOT NULL DEFAULT '0' COMMENT '评论数',
  `is_top` tinyint NOT NULL DEFAULT '0' COMMENT '是否置顶：1是，0否',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态：1正常，0删除',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`post_id`),
  KEY `idx_forum_post_board_id` (`board_id`),
  KEY `idx_forum_post_author_id` (`author_id`),
  KEY `idx_forum_post_create_time` (`create_time`),
  CONSTRAINT `fk_forum_post_author` FOREIGN KEY (`author_id`) REFERENCES `sys_user` (`user_id`),
  CONSTRAINT `fk_forum_post_board` FOREIGN KEY (`board_id`) REFERENCES `forum_board` (`board_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='帖子表';


CREATE TABLE `forum_comment` (
  `comment_id` bigint NOT NULL AUTO_INCREMENT COMMENT '评论ID',
  `post_id` bigint NOT NULL COMMENT '所属帖子ID',
  `user_id` bigint NOT NULL COMMENT '评论用户ID',
  `parent_comment_id` bigint DEFAULT NULL COMMENT '父评论ID（一级评论为NULL）',
  `reply_user_id` bigint DEFAULT NULL COMMENT '被回复用户ID',
  `content` text COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '评论内容',
  `like_count` int NOT NULL DEFAULT '0' COMMENT '点赞数',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态：1正常，0删除',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`comment_id`),
  KEY `idx_forum_comment_post_id` (`post_id`),
  KEY `idx_forum_comment_user_id` (`user_id`),
  KEY `idx_forum_comment_parent_comment_id` (`parent_comment_id`),
  KEY `fk_forum_comment_reply_user` (`reply_user_id`),
  CONSTRAINT `fk_forum_comment_parent` FOREIGN KEY (`parent_comment_id`) REFERENCES `forum_comment` (`comment_id`),
  CONSTRAINT `fk_forum_comment_post` FOREIGN KEY (`post_id`) REFERENCES `forum_post` (`post_id`) ON DELETE CASCADE,
  CONSTRAINT `fk_forum_comment_reply_user` FOREIGN KEY (`reply_user_id`) REFERENCES `sys_user` (`user_id`),
  CONSTRAINT `fk_forum_comment_user` FOREIGN KEY (`user_id`) REFERENCES `sys_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='评论表';


CREATE TABLE `forum_like` (
  `like_id` bigint NOT NULL AUTO_INCREMENT COMMENT '点赞ID',
  `target_type` tinyint NOT NULL COMMENT '点赞目标类型：1-帖子，2-评论',
  `target_id` bigint NOT NULL COMMENT '目标ID（帖子ID或评论ID）',
  `user_id` bigint NOT NULL COMMENT '点赞用户ID',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`like_id`),
  UNIQUE KEY `uk_forum_like_target_user` (`target_type`,`target_id`,`user_id`) COMMENT '确保同一用户不重复点赞同一目标',
  KEY `idx_forum_like_user_id` (`user_id`),
  KEY `idx_forum_like_target` (`target_type`,`target_id`),
  CONSTRAINT `fk_forum_like_user` FOREIGN KEY (`user_id`) REFERENCES `sys_user` (`user_id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='点赞表（支持帖子和评论）';
```

### 索引说明

| 表名 | 索引名 | 类型 | 字段 | 用途 |
|------|--------|------|------|------|
| sys_user | uk_sys_user_username | UNIQUE | username | 登录账号唯一 |
| forum_board | uk_forum_board_name | UNIQUE | board_name | 板块名称唯一 |
| forum_post | idx_forum_post_board_id | 普通 | board_id | 按板块查帖子 |
| forum_post | idx_forum_post_author_id | 普通 | author_id | 按作者查帖子 |
| forum_post | idx_forum_post_create_time | 普通 | create_time | 按时间排序 |
| forum_comment | idx_forum_comment_post_id | 普通 | post_id | 按帖子查评论 |
| forum_comment | idx_forum_comment_user_id | 普通 | user_id | 按用户查评论 |
| forum_comment | idx_forum_comment_parent_comment_id | 普通 | parent_comment_id | 查子评论 |
| forum_comment | fk_forum_comment_reply_user | 普通 | reply_user_id | 被回复用户查询 |
| forum_like | uk_forum_like_target_user | UNIQUE | target_type, target_id, user_id | 防重复点赞 |
| forum_like | idx_forum_like_user_id | 普通 | user_id | 按用户查点赞 |
| forum_like | idx_forum_like_target | 普通 | target_type, target_id | 按目标查点赞 |

> **注意**：`forum_like` 通过 `target_type` + `target_id` 逻辑关联帖子或评论，**未设置**指向 `forum_post` 或 `forum_comment` 的外键约束。删除帖子/评论时，代码层在事务中通过 `forumLikeMapper.deleteByTarget()` 手动清理关联点赞记录，避免孤儿数据。

## 三、Spark 离线分析统计表

### 1. 设计说明

为满足课程设计"使用 Spark 做数据分析"的要求，并避免对在线业务表做多次全表 COUNT 聚合，新增 6 张统计表，由服务器上的 Spark 程序（`/opt/forum-stats.jar`）每日凌晨 03:00 通过 cron 跑批覆盖写入。Spring Boot 端通过 `StatMapper` 只读展示，统计数据容忍日级延迟。

数据流：

```
Spark 程序(独立 JVM, Java 21) --JDBC--> 读取业务表(sys_user/forum_board/forum_post/forum_comment/forum_like)
            |
        聚合计算
            |
            v --JDBC 覆盖写入--> stat_* 统计表 <--只读-- Spring Boot(StatMapper -> StatisticsService)
```

### 2. 统计表清单

| 表名 | 说明 | 写入方式 | 主键 |
|------|------|---------|------|
| `stat_overview` | 统计概览快照（用户/板块/帖子/评论/点赞总数） | 覆盖写固定 id=1 行 | `id` |
| `stat_hot_post` | 热门帖子榜（Top 50，按热度分排序） | 整表清空重写 | `rank_num` |
| `stat_board_active` | 板块活跃度（按活跃度排序） | 整表清空重写 | `board_id` |
| `stat_active_user` | 用户活跃度排行（Top 50） | 整表清空重写 | `rank_num` |
| `stat_content_quality` | 内容质量分析（按质量分类） | 整表清空重写 | `post_id` |
| `stat_daily_trend` | 每日趋势（按天） | 全量按天聚合后覆盖写 | `stat_date` |

### 3. 计算口径

| 表 | 计算公式 |
|----|---------|
| `stat_hot_post.hot_score` | 点赞数×2 + 评论数×3 + 浏览量×0.1 |
| `stat_board_active.active_score` | 帖子数×5 + 点赞数×2 + 评论数×3 + 浏览量×0.1 |
| `stat_active_user.active_score` | 发帖数×5 + 评论数×2 + 获赞数×1（获赞 = 帖子被点赞数 + 评论被点赞数） |
| `stat_content_quality` | `HIGH_LIKE_LOW_COMMENT`：点赞≥10且评论≤5；`HIGH_COMMENT_LOW_LIKE`：评论≥8且点赞≤3；`HOT`：热度≥40 |
| `stat_daily_trend` | 按 `create_time` 日期分组统计当日新增量 |

### 4. 建表脚本

建表脚本见仓库根目录 `spark_stats.sql`，演示数据见 `spark_demo_data.sql`。

### 5. 与业务表的关系

统计表是业务表的派生数据，**不与业务表建立外键约束**，原因：

1. 统计表由 Spark 程序独立写入，与 Spring Boot 事务解耦，避免外键约束影响跑批。
2. 业务表数据删除时，统计表会在下一次跑批时自动同步（覆盖写）。
3. 统计表允许短暂的数据不一致（最长 24 小时），符合离线分析的容忍度。

### 6. 代码侧映射

- 实体类：`StatOverview`、`StatHotPost`、`StatBoardActive`、`StatActiveUser`、`StatContentQuality`、`StatDailyTrend`
- Mapper：`StatMapper`（接口） + `StatMapper.xml`（SQL）
- Service：`StatisticsService` / `StatisticsServiceImpl`（读取统计表展示）
- Spark 程序：`spark-stats` 模块，`ForumSparkAnalysis.java`

# 后端接口清单

## 一、通用约定

### 基础配置

- **Base URL**: `/api`
- **认证**: `Authorization: Bearer <token>`（除 login/register/oauth 外必需）
- **Content-Type**: `application/json`
- **文件上传**: `multipart/form-data`

### 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

### 分页响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "pageSize": 20,
    "hasMore": true
  }
}
```

### 分页查询参数（通用）

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| page | number | 1 | 页码 |
| pageSize | number | 20 | 每页数量 |

### 状态码约定

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数错误 |
| 40100 | 未登录 |
| 40101 | token 过期 |
| 40300 | 无权限 |
| 40400 | 资源不存在 |
| 50000 | 服务器错误 |

## 九、建议补充说明

- **WebSocket（可选）**: 实时通知、新评论推送、在线状态
- **字段命名**: 统一 camelCase（前端）或 snake_case（后端）需约定，建议后端转 camelCase 输出
- **时间字段**: 统一返回 ISO 8601 + 显示文本（如 `createdAt` + `createdAtText`），前端避免再做相对时间转换
- **图片字段**: 全部返回完整 URL，不要返回相对路径
- **统计数字**: 大数字建议后端返回展示文本（如 `"2.4k"`），前端直接用

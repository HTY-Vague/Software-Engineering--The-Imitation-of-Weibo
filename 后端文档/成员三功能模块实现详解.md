# 成员三（前端开发）功能模块实现详解

> 本文档按功能模块逐一梳理成员三在前端项目中完成的所有开发工作，包含功能描述、技术栈与关键实现思路，供课程设计报告参考。

---

## 一、项目基础架构

### 1.1 前端工程搭建

| 项目 | 说明 |
|------|------|
| **功能描述** | 从零搭建 Vue 3 + Vite 前端工程，配置所有依赖、构建工具和开发环境 |
| **技术栈** | Vite 8、npm、Node.js 18+ |
| **实现思路** | 使用 `npm create vite@latest` 初始化，按需安装 Element Plus / Axios / Pinia / Vue Router / WangEditor / ECharts 等依赖；配置 `vite.config.js` 使用 `cssMinify: 'esbuild'` 解决 lightningcss 压缩 scoped CSS 时的兼容性问题；配置 `.env.development` 和 `.env.production` 管理后端地址环境变量 |

**关键文件**：`package.json`、`vite.config.js`、`.env.development`、`.env.production`

---

### 1.2 HTTP 请求封装

| 项目 | 说明 |
|------|------|
| **功能描述** | 封装 Axios 统一请求实例，提供请求拦截（自动注入 JWT token）和响应拦截（统一处理业务码、401 自动登出） |
| **技术栈** | Axios |
| **实现思路** | 创建 `services/http.js`，通过 `axios.create()` 新建实例并配 `baseURL` 与 `timeout`；在 `request` 拦截器中从 localStorage 读取 token 写入 `Authorization: Bearer <token>` 头；在 `response` 拦截器中根据 `code === 200` 判断成功/失败，401 时清除本地存储并跳转登录页 |

**关键文件**：`services/http.js`

---

### 1.3 接口服务层封装（8 个模块）

| 项目 | 说明 |
|------|------|
| **功能描述** | 将后端 REST API 按业务模块封装为独立的 JS 服务文件，页面中通过导入函数调用接口 |
| **技术栈** | Axios、ES Module |
| **实现思路** | 每个模块对应一个 `.js` 文件，统一从 `http.js` 导入实例，使用 `http.get()` / `http.post()` 等方法导出函数 |

| 模块文件 | 封装的接口 |
|---------|-----------|
| `auth.js` | `login()` / `register()` |
| `user.js` | `getProfile()` / `updateProfile()` / `updatePassword()` / `getMyPosts()` / `getMyComments()` |
| `forum.js` | `getBoards()` / `getBoardPosts()` |
| `post.js` | `getPosts()` / `getPostDetail()` / `createPost()` / `updatePost()` / `deletePost()` / `searchPosts()` |
| `comment.js` | `getComments()` / `createComment()` / `deleteComment()` |
| `like.js` | `getLikeStatus()` / `toggleLike()` |
| `admin.js` | `getUsers()` / `updateUserStatus()` / `deletePost()` / `deleteComment()` / `createBoard()` / `updateBoard()` / `deleteBoard()` / `setPostTop()` |
| `statistics.js` | `getOverview()` / `getHotPosts()` / `getBoardActive()` / `getActiveUsers()` / `getContentQuality()` / `getDailyTrend()` / `triggerSpark()` / `getSparkStatus()` |

**关键文件**：`services/modules/*.js`（8 个文件）

### 1.4 路由管理

| 项目 | 说明 |
|------|------|
| **功能描述** | 配置 SPA 路由表，实现页面懒加载、导航守卫（登录鉴权 + 角色权限控制） |
| **技术栈** | Vue Router 4、Pinia |
| **实现思路** | 路由采用 `() => import()` 懒加载所有页面组件；`beforeEach` 导航守卫读取 Pinia store 中的 token 和 role，对 `meta.requiresAuth` 路由校验登录态，对 `meta.requiresAdmin` 路由校验管理角色，拦截后跳转 `/login` 或首页 |

### 1.5 状态管理

| 项目 | 说明 |
|------|------|

## 二、用户认证模块

### 2.1 登录页（LoginPage）

| 项目 | 说明 |
|------|------|
| **功能描述** | 用户名/密码登录表单，登录成功后存储 JWT token 并跳转首页；失败时显示错误提示 |
| **技术栈** | Vue 3 Composition API、Element Plus (el-form / el-input / el-button)、Axios、Pinia、Vue Router |
| **实现思路** | `el-form` 绑 `rules` 校验用户名和密码非空 + 长度限制；提交时 `await formRef.validate()` 通过后调用 `login(username, password)` → 后端返回 `{ token, user }` → `authStore.setAuth(token, user)` 写入 Pinia + localStorage → `router.push('/')`；错误时 `ElMessage.error()` 弹消息 |

**关键文件**：`pages/auth/LoginPage.vue`

---

| **功能描述** | 管理后台数据统计与可视化页面，包含：① 6 项统计概览卡片（用户/活跃用户/板块/帖子/评论/点赞总数，含最近更新时间）；② 热门帖子排行表（排名/热度分/浏览量/点赞/评论）；③ 板块活跃度排行表（活跃度评分）；④ 用户活跃度排行表；⑤ 内容质量分析（三分类 Tab 切换）；⑥ **饼状图**（环形图，展示内容质量分布——高赞低评论/高评论低赞/综合热门三类占比）；⑦ **柱状图**（分组柱，TOP 10 板块的帖子数/点赞数/评论数三维对比）；⑧ **每日趋势折线图**（4 条平滑曲线——新增用户/帖子/评论/点赞）；⑨ **Spark 跑批触发与轮询**（点击"刷新统计"触发 Spark → 每 2 秒轮询状态 → 成功后自动刷新全页；5 分钟超时兜底；800ms 防抖） |
| **技术栈** | Vue 3 Composition API、Element Plus (el-button / el-table / el-tabs / el-tag / el-pagination)、**ECharts 5 按需引入**（LineChart + BarChart + PieChart + GridComponent + TitleComponent + TooltipComponent + LegendComponent + CanvasRenderer）、Axios、ResizeObserver API |
| **实现思路** | ① `loadAll()` 方法使用 `Promise.all()` 并发请求 8 个统计接口，数据全部返回后统一渲染；② 概览卡片使用 `computed` 从 `overview` 对象中提取 6 项指标，`v-for` 循环渲染；③ 排行榜表格使用 `el-table` 展示后端返回的排行数据；④ 内容质量分析使用 `el-tabs` + `@tab-change` 切换 `qualityType` 参数，过滤 `computed` 后的 `qualityItems` 渲染对应分类；⑤ **饼状图**：从 `qualityData` 按 `qualityType` 分组计数，环形饼图 `radius: ['45%', '75%']` 展示三类占比，颜色使用绿/橙/红区分；⑥ **柱状图**：从 `boardActive` 取 TOP 10，三条 `series` 分别渲染帖子数/点赞数/评论数，`axisPointer: { type: 'shadow' }` 实现阴影指示；⑦ **折线图**：`dailyTrend` 按日期排序后绘制 4 条 `smooth: true` 曲线，`tooltip.trigger: 'axis'` 十字准星效果；⑧ **跑批轮询**：`onRefresh()` → `triggerSpark()` → `pollSparkStatus()` 启动 `setInterval(2s)` 轮询 → 状态变为 `SUCCESS` 时 `clearInterval` + `loadAll()` 重载；`sparkDeadline` 变量实现 5 分钟超时强制停止；`lastTriggerAt` 变量实现 800ms 防抖；⑨ 三个图表容器均用 `ResizeObserver` 监听尺寸变化自动 resize；`onBeforeUnmount` 统一销毁 3 个 ECharts 实例防止内存泄漏 |
| **接口依赖** | `getOverview()` / `getHotPosts()` / `getBoardActive()` / `getActiveUsers()` / `getContentQuality()` / `getDailyTrend()` / `triggerSpark()` / `getSparkStatus()` — 全部封装于 `services/modules/statistics.js` |

**关键文件**：`pages/admin/StatisticsPage.vue`（约 750 行，前端最复杂的单页面组件）

## 十、技术栈总览

| 类别 | 技术/库 | 用途 |
|------|---------|------|
| 前端框架 | Vue 3 (Composition API + `<script setup>`) | 所有页面的组件化开发 |
